# 🔄 Active Documents (현재 참고용)

이 폴더는 현재 시스템에서 지속적으로 참고하고 업데이트되는 문서들입니다.

## 📋 포함된 문서들

### 🔌 api_spec.md
- **현재 API 명세서 v0.1.0**
- 모든 엔드포인트 상세 스펙
- 요청/응답 형식, 오류 처리
- 새로운 API 추가 시 업데이트 필요

### 🗄️ db_schema.md  
- **데이터베이스 스키마 정의**
- answers 테이블 구조
- SQLite → Supabase 마이그레이션 계획
- 스키마 변경 시 업데이트 필요

### 📝 sample_test.md
- **실제 심리테스트 콘텐츠**
- 10문항 + 8가지 결과 유형
- v0.2.0 JSON 변환 시 기준 자료
- 새로운 테스트 추가 시 참고

## 🎯 사용 지침

### 개발 중 참고
- API 개발 시 → `api_spec.md` 확인
- DB 작업 시 → `db_schema.md` 확인  
- 콘텐츠 작업 시 → `sample_test.md` 확인

### 업데이트 시점
- ✅ **API 변경**: 새로운 엔드포인트 추가/수정
- ✅ **DB 스키마 변경**: 테이블 구조 수정
- ✅ **콘텐츠 변경**: 새로운 테스트 추가

### 버전 관리
- 각 문서 하단에 변경 이력 기록
- 주요 변경 시 버전 번호 업데이트
- Git 커밋 메시지에 문서 변경 내용 포함
