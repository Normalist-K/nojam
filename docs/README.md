# 📚 Documentation Structure

이 폴더는 프로젝트의 모든 문서를 단계별로 정리한 구조입니다.

## 📁 폴더 구조

```
docs/
├── README.md                 # 이 파일 - 문서 구조 설명
├── design.md                 # 🎯 프로젝트 최종 목표 설계서
├── archived/                 # ✅ 완료된 구현 (v0.1.0)
├── active/                   # 🔄 현재 참고용 문서
└── future/                   # 🚀 향후 계획 문서
```

## 📋 분류 기준

### 🎯 design.md - 프로젝트 최종 목표
전체 프로젝트를 아우르는 최상위 설계서
- JSON-driven 심리테스트 플랫폼 비전
- v0.1.0 ~ v1.0.0 전체 로드맵
- 기술 스택, 아키텍처, 비즈니스 모델
- 프로젝트 끝까지 지속적으로 참고

### ✅ archived/ - 완료된 구현
v0.1.0에서 구현이 완료되어 더 이상 수정되지 않는 문서들
- 기록 보관 목적
- 과거 의사결정 추적 가능
- 새로운 팀원 온보딩 시 참고

### 🔄 active/ - 현재 참고용
지속적으로 참고하고 업데이트되는 문서들
- API 스펙, DB 스키마 등 현재 시스템 문서
- 개발 중 자주 참조하는 자료
- 버그 수정이나 기능 추가 시 업데이트 필요

### 🚀 future/ - 향후 계획
v0.2.0 이후 구현 예정인 기능과 계획 문서들
- 로드맵, TODO 리스트
- 아직 구현되지 않은 기능의 설계서
- 실험적 아이디어와 제안서

## 📖 현재 상태 (v0.1.0 기준)

### 구현 완료 ✅
- 기본 프로젝트 구조
- FastAPI 웹 애플리케이션
- SQLite 기반 데이터베이스
- 심리테스트 로직 (하드코딩)
- Stub 기반 외부 연동
- 기본 웹 UI (TailwindCSS)
- CI/CD 파이프라인
- 단위 테스트 (7개)

### 다음 단계 🎯
- JSON-driven 심리테스트 플랫폼 (v0.2.0)
- E2E 테스트 환경 개선
- 실제 광고 SDK 연동
- 고급 로깅 및 모니터링
