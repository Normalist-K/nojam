# 🧪 “수다로 알아보는 내 대화 스타일” – 5060 심리테스트 (일상 언어 버전)

| 번호 | 질문 (일상체) | 주요 반응 예 | 분기되는 대화유형 |
| --- | --- | --- | --- |
| 1 | **“어떻게 지내세요?” 하면 괜히 근황 30분 떠들고 싶다.** | O: 스토리 많음 / X: 짧게 말함 | O → 이야기꾼형 (C)<br>X → 조용조용형 (B) |
| 2 | **요즘 좀 울컥하는 일이 많다. 드라마 보다가도 훌쩍.** | O: 감정적 / X: 무덤덤 | O → 감정형 (A)<br>X → 사실형 (G) |
| 3 | **“그땐 몇 년이었지…”부터 말이 시작된다.** | O: 연도부터 / X: 대충 얘기함 | O → 타임머신형 (E)<br>X → 감정형 (A) |
| 4 | **내 얘기보다 가족 얘기가 더 자연스럽다.** | O: 부모·배우자·자녀 이야기 / X: 자기 중심 | O → 인물 위주형 (D)<br>X → 지휘형 (I) |
| 5 | **말 많은 사람 보면 난 “아이고, 난 못 하겠다” 싶다.** | O: 내향 / X: 수다 좋아함 | O → 조용조용형 (B)<br>X → 이야기꾼형 (C) |
| 6 | **사람한테 상처받은 얘기 하면 아직도 울컥한다.** | O: 감정 표현 / X: 건조하게 말함 | O → 감정형 (A)<br>X → 사실형 or 원칙형 (G, F) |
| 7 | **내가 한 말에 내가 감탄하거나 후회하는 편이다.** | O: 자기 반성 / X: 쿨함 유지 | O → 혼잣말형 (H)<br>X → 회피형 (J) |
| 8 | **“그땐 내가 참 바보였지” 하는 말 자주 한다.** | O: 자기성찰 / X: 외부탓 or 회피 | O → 혼잣말형 (H)<br>X → 회피 개그형 (J) |
| 9 | **이야기하다 보면 내가 질문하고 내가 대답하고 있다.** | O: 주도적 / X: 리드 따름 | O → 토크쇼형 (I)<br>X → 관계형 or 감정형 (D, A) |
| 10 | **“원래 나는 말이지”로 시작하는 말 자주 한다.** | O: 자기 철학 있음 / X: 즉흥적 | O → 원칙형 (F)<br>X → 감정형 or 회피형 (A, J) |
| 11 | **웃기려고 한 말 아닌데 다들 웃는다.** | O: 회피성 유머 or 정서 회피 / X: 진지함 | O → 회피 개그형 (J)<br>X → 자기성찰형 or 사실형 |
| 12 | **“그 얘기는 좀 그렇고…” 하면서 돌려 말하는 편이다.** | O: 불편 회피 / X: 직설적 | O → 회피형 (J)<br>X → 지휘형 or 신념형 (I, F) |
| 13 | **누가 “그땐 어땠어요?” 하면 시간·장소부터 떠올린다.** | O: 시점 기억 중심 / X: 감정 중심 | O → 타임머신형 (E)<br>X → 감정형 or 스토리형 (A, C) |
| 14 | **“내 인생도 책 한 권쯤은 되지”란 말 해본 적 있다.** | O: 서사 욕망 / X: 관심 없음 | O → 이야기꾼형 (C)<br>X → 사실형 or 조용형 |
| 15 | **진지한 얘기 나올 때 분위기 풀려고 농담하는 편이다.** | O: 유머로 회피 / X: 그대로 받아침 | O → 회피 개그형 (J)<br>X → 감정형 or 자기성찰형 |

# 🎯 요약 – 10가지 대화유형 & 코드

| 코드 | 유형 이름 | 설명 키워드 |
| --- | --- | --- |
| A | 🎭 감정형 인간 | 감정이 먼저, 눈물 많음 |
| B | 🐢 조용조용 인간 | 말 적고 속 깊은 내향형 |
| C | 📜 이야기꾼 인간 | 서사적, 대화의 드라마 제작자 |
| D | 🧓 인물 위주 인간 | 자기 얘기보다 가족 이야기 위주 |
| E | ⏳ 타임머신 인간 | 기억은 시간표로 저장됨 |
| F | 🧱 원칙형 인간 | 신념·철학 중심, 단단함 |
| G | 📊 보고서 인간 | 정보 중심, 감정은 줄임 |
| H | 🪞 혼잣말 인간 | 자기반성, 내면이야기 많음 |
| I | 🎙️ 토크쇼 인간 | 질문부터 진행까지 내가 한다 |
| J | 🐸 회피 개그 인간 | 진지함 회피, 유머로 포장 |
