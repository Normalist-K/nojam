# 공유 이미지 폴더

이 폴더는 SNS 공유 시 사용되는 이미지들을 저장합니다.

## 파일 명명 규칙

### 결과별 공유 이미지
- `{result_type}.jpg` - 각 결과 유형별 공유 이미지
- 예: `7080.jpg`, `IMF.jpg`, `ESTJ.jpg`

### 기본 이미지
- `default.jpg` - 결과별 이미지가 없을 때 사용되는 기본 이미지

## 이미지 사양

### 권장 사이즈
- **카카오톡**: 800x400px (2:1 비율)
- **네이버 밴드**: 1200x630px (1.91:1 비율)
- **공통 권장**: 1200x630px (OG 표준)

### 파일 형식
- JPEG (.jpg) - 용량 효율성
- PNG (.png) - 투명 배경 필요시

## 자동 생성 계획

향후 다음 기능들을 추가 예정:
1. 결과 카드 HTML을 이미지로 변환하는 API
2. 동적 이미지 생성 (결과 내용 반영)
3. 이미지 캐싱 및 최적화
