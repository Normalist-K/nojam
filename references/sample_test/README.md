# 📝 Sample Test - 마음나이 테스트

이 폴더는 JSON-driven 심리테스트 플랫폼의 첫 번째 샘플 테스트입니다.

## 📁 파일 구성

### 📄 sample_test.md
- **원본 마크다운 파일** (참고용)
- 8가지 결과 유형과 15개 문항 정의
- JSON 변환의 기준이 된 원본 콘텐츠

### 🎨 card.html
- **결과 카드 HTML 템플릿** (참고용)
- 8개 결과 유형별 카드 디자인
- CSS 스타일과 그라데이션 정보 포함
- JSON의 `style` 필드 설계 기준

### 📋 mind-age-test.json
- **JSON Schema v2.1 기반 테스트 설정**
- 실제 플랫폼에서 사용할 JSON 파일
- sample_test.md의 모든 내용을 JSON으로 변환

### 🔧 quiz-schema-v2.1.json
- **JSON Schema 검증 파일**
- JSON 파일의 구조와 데이터 타입 검증
- 개발 시 IDE에서 자동완성 지원

## 🎯 주요 특징

### 점수 시스템: `simple_count`
- 각 선택지가 특정 결과 유형에 1점 부여
- 최다 득점 유형이 최종 결과
- 동점 시 알파벳순 결정

### 결과 유형 (8가지)
1. **7080** - 7080 감성형 (통기타, 낭만)
2. **IMF** - IMF 생존형 (절약, 현실)
3. **ACT** - 운동권 열혈형 (정의, 사회의식)
4. **MBC** - MBC드라마형 (가족, 감성)
5. **PHONE** - 폰 적응형 (스마트폰, 적응)
6. **ANA** - 아날로그 고수형 (수첩, 전통)
7. **TREND** - 유행 선도형 (트렌드, 스타일)
8. **JUNK** - 정크컬쳐 수집형 (복고, 레트로)

### 카드 스타일
- 각 유형별 고유 그라데이션 색상
- 원형 숫자 (①②③④⑤⑥⑦⑧)
- CSS 클래스 (type-1, type-2, ...)
- 대표 이모지 및 키워드
